05 / DIGITAL EXPERIENCE

星火沉浸

标语互动与数字体验

让档案不只被阅读，也能在选择、比较、拼合与修复中被重新理解。每项体验都对应一个明确的历史问题。

互动项目推荐体验内容原则
CHOICE / CONTEXT / MEMORY

红军不怕
远征难

在历史情境中理解信念如何转化为行动
01 / PROJECTS互动项目

四种体验，连接策略、文字、空间与人物

当前先搭建项目入口和说明，后续可逐个接入真正的游戏页面、关卡数据和数字资源。

GAME / 01

《井冈山保卫战》策略互动

在有限资源与复杂环境中处理群众动员、物资筹备、组织建设和防御选择，理解历史行动的多重约束。

  • 预计体验 12—18 分钟
  • 适合课堂分组讨论
  • 每次选择附史料说明
CHALLENGE / 02

标语闯关与时期判断

根据文字主题、传播对象和历史语境判断标语所属时期，再查看依据与关联档案。

RESTORE / 03

标语拼图与数字修复

从模糊、缺损的墙面影像中拼合文字，体验档案修复前的观察、辨识与记录过程。

ATLAS / 04

地图、情境与人物图鉴

按地点进入历史场景，查看代表人物、相关事件、标语档案与团队寻访记录。

02 / PATH推荐体验路径

第一次进入，从五分钟的标语闯关开始

用由浅入深的顺序降低理解门槛，再把互动中产生的问题带回数字档案和研究文章。

  1. 05 MIN先做三道标语判断

    建立时期、主题和对象的初步区别。

  2. 08 MIN完成一幅旧墙数字修复

    观察文字载体、缺损位置与可能的辨识依据。

  3. 15 MIN进入《井冈山保卫战》

    把表达放回组织、资源和群众工作的实际约束中。

  4. OPEN回到档案与研究核对

    打开相关标语、人物和地点，检验互动中形成的判断。

03 / RULES内容原则

沉浸不是虚构历史，而是让史料关系更容易被看见

游戏机制可以简化操作，但不能随意改写事实；重要选择需要说明历史依据、艺术加工与不确定之处。

设计部分可以简化必须保留呈现方式
策略互动资源数量、回合长度和操作步骤历史任务、重要关系与选择后果关卡说明 + 史料卡片
数字修复拼图尺寸和操作难度原图、缺损状态与辨识不确定性修复前后对照 + 原始档案链接
人物图鉴信息层级和阅读顺序姓名、身份、经历、出处与时间人物卡 + 事件与地点关联

互动之后，回到真实档案

查看标语原文、地点、年代和历史背景，完成从体验到研究的闭环。
