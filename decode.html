01 / COMMON共同点与传承性

从井冈山到长征，标语文化一脉相承

两个时期都将标语视为"战斗号角"和"精神武器"，核心目的都是为了争取群众、瓦解敌军、鼓舞士气。

A / 本质

宣传本质一致

两个时期都将标语视为"战斗号角"和"精神武器"，是在敌强我弱、信息闭塞环境下最有效的群众工作手段。

B / 手法

制作手法延续

长征时期的手写、木刻、石刻和"水电报"等传播方式，直接继承了井冈山时期的成熟经验。

C / 原则

创作原则一贯

两个时期的标语都追求"通俗易懂、简明有力、紧贴实际"，用老百姓听得懂的话讲老百姓关心的事。

D / 领导

领导重视的延续

从毛泽东、陈毅在井冈山带头制定规范、亲自书写，到长征时期《红星报》发文号召，领导层高度重视宣传工作的传统充分延续。

02 / CONTRAST差异点与发展性

从"扎根"到"播种"：标语功能与形式的演进

井冈山是红色标语文化的"摇篮"和"试验田"；长征则是将这些经验应用到万水千山、多民族复杂环境中的伟大实践。

03 / INFLUENCE影响背景

井冈山经验如何影响长征标语

井冈山时期为党和红军提供了一整套"在极端困境中开展有效宣传"的成熟解决方案和宝贵经验。

01 / 破局

解决"军队与群众隔离"的难题

井冈山时期首次证明：墙上一条条直接宣示主张的标语，是比面对面接触更先一步、门槛更低的沟通方式。长征红军进入陌生地域时，立刻熟练运用这套方法，先写标语表明身份和宗旨，消除群众的恐慌。

02 / 制度

形成"因陋就简、高效多产"的工作制度

陈毅发布《红色标语注意事项》，对字迹、书写位置、署名格式做详尽规定，标志宣传工作从个人行为走向制度化。设立宣传队、"钻花队"等专业分工，这套制度直接带到长征路上。

03 / 导向

确立"贴近群众切身利益"的内容导向

井冈山标语的力量源于讲"打倒土豪分田地""保护小商人贸易"等切身利益。长征中，进入贵州就反对军阀王家烈，进入四川就反对刘湘——将抽象目标与当地民众最痛恨的具体敌人结合，这正是"实事求是"作风的直接体现。

04 / 传统

传承"全军动手、群众参与"的全员模式

毛泽东要求部队"担负武装和宣传队的任务"，领导干部带头、普通士兵参与。这种"人人都是宣传员"的组织模式深入军心，使长征做到"部队走到哪里，宣传就做到哪里"。
